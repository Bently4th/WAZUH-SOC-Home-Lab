# WAZUH-SOC-Home-Lab

Welcome to my Wazuh SOC Home Lab project!

I'm a cybersecurity student working toward my B.S. in Cybersecurity, having already earned my A.A.S. in Cybersecurity.

As I prepare to enter the cybersecurity workforce, particularly as a SOC Analyst, I wanted to challenge myself to build something hands-on rather than rely solely on what I've learned in the classroom.

After speaking with a cybersecurity professional about ways to strengthen my technical experience, I decided to build my own Security Operations Center (SOC) home lab.

I chose Wazuh, an open-source Security Information and Event Management (SIEM) platform, because it's free to use and gives me an opportunity to practice monitoring, detecting, and investigating security events.

Purpose of This Repository

My goal is to document my journey from installing Wazuh to developing practical security monitoring and incident response skills.

This repository will include:

Step-by-step installation instructions

Commands I used to get Wazuh running

Problems I encountered and how I solved them

Screenshots documenting my progress

Future security monitoring and threat detection exercises

Lessons learned along the way

I also want this repository to be useful to other students and beginners who are interested in building their own SOC home lab but aren't sure where to start.
